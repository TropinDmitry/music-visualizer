# Что дальше: монетизация, конкуренты, фишки

Значком 🔎 отмечено всё, что написано по памяти и требует проверки перед решениями: цены, тарифы и возможности чужих продуктов меняются часто.

## 1. Монетизация (без подписки)

Исходная идея — разовые платежи. Какие варианты подходят прототипу.

| Модель | Как выглядит | Плюсы | Минусы |
|---|---|---|---|
| **Оплата за экспорт без водяного знака** | Бесплатно с водяным знаком, за $2–5 (🔎 проверить ожидания рынка) — один чистый ролик | Платят ровно тогда, когда получают ценность | Нужна проверка оплаты на сервере, иначе водяной знак выключат в DevTools |
| **Пакеты кредитов** | 10 экспортов за $X; кредиты не сгорают | Привычно, повышает средний чек | Нужен учёт кредитов (бэкенд) |
| **Наборы стилей** | Базовые 3 стиля бесплатно, «Synthwave pack», «Lo-fi pack» — разово | Контент можно выпускать отдельно и продавать снова | Стили надо постоянно делать |
| **Pro навсегда (lifetime)** | Одна покупка: все стили, без водяного знака, 4K | Просто объяснить; разовые покупки нравятся музыкантам | Нет повторной выручки, кроме новых паков |
| **Лицензия для лейблов и студий** | Свой брендинг вместо водяного знака, пакетный рендер | Крупные чеки | Нужны продажи и поддержка |

Что важно технически:

- **Водяной знак нельзя защитить в браузере.** Код открыт, и его можно выключить. Варианты:
  - мириться с этим: платят честные пользователи, а это большинство;
  - отдавать платные стили (шейдеры) только после оплаты, с сервера по токену;
  - финальный рендер без водяного знака делать на сервере (headless Chrome + та же кодовая база). Это дорого.
- Самый дешёвый старт:
  - статический хостинг;
  - платёжка с готовым checkout (🔎 Lemon Squeezy / Paddle / Stripe Checkout; для РФ — ЮKassa, CloudPayments; проверить, кто работает с самозанятыми);
  - лицензионный ключ, который открывает Pro в `localStorage`.
- Для РФ-аудитории (ВК-клипы): учесть, что зарубежные платёжки там недоступны 🔎.

## 2. Конкуренты (🔎 всё проверить)

| Продукт | Что это | Модель (🔎) | Чем мы можем отличаться |
|---|---|---|---|
| Specterr | Онлайн-конструктор аудиовизуализаций | Подписка, водяной знак на бесплатном | Без подписки, рендер локально, быстрее |
| Renderforest (Music Visualization) | Шаблоны видео, в т.ч. визуализаторы | Подписка / оплата за экспорт | Живое превью, тонкая настройка, реакция на удары |
| VEED, Kapwing (audio waveform) | Видеоредакторы с «волной» поверх видео | Подписка | Полноценная генеративная графика, а не только волна |
| Videobolt | Шаблоны After Effects в облаке | Подписка | Мгновенное превью, нет очереди рендера |
| Rotor Videos | Клипы из стоковых видео под трек | Оплата за видео | Процедурная графика, никаких стоков |
| Plane9, Magic Music Visuals, Synesthesia | Десктопные VJ-программы | Разовая покупка | В браузере, без установки, сразу готовый ролик под соцсети |

| NCS-подобные каналы, «Avee Player» (мобильный) | Визуализаторы-спектры | Freemium | Качество 1080p/60 и стили «как у NCS», но свои |

Вывод из таблицы (гипотеза, не факт): ниша «без подписки + рендер у себя в браузере + синхронизация с ударами» выглядит незанятой. Проверить:

- поиском по «audio visualizer maker no subscription»;
- в сообществах музыкантов: r/WeAreTheMusicMakers, чаты битмейкеров, ВК-паблики продюсеров.

## 3. Фишки, которые могут отличить продукт

**Сильнее всего отличают:**

1. **Понимание структуры трека.** Не только удары, но и куплет/припев/дроп: новизна спектра на длинных окнах плюс рост RMS. Стиль меняется на дропе, например сфера «взрывается». Конкуренты с простыми спектрами так не умеют 🔎.
2. **Темп и сетка долей.** Оценка BPM по автокорреляции onset-функции. Тогда эффекты можно ставить строго на доли и такты, а не на каждый всплеск.
3. **Обложка трека в кадре.** Загрузить картинку и использовать её как текстуру, палитру (извлечь цвета обложки) или фон с параллаксом. Музыкантам очень важно «в цветах релиза».
4. **Пакет для релиза одним кликом.** Сразу три файла: 16:9 полный трек, 9:16 на 15 и 30 с с лучшего места (автоматически выбрать самый энергичный фрагмент), квадрат. Плюс превью-GIF.
5. **Караоке-текст и тайм-коды.** Импорт LRC и подпись строк в такт.

**Полезное улучшение качества:**

- Пост-обработка: bloom, film grain, хроматическая аберрация. Есть в `three/examples` (EffectComposer), детерминированность сохраняется.
- Разделение на стемы (бас, ударные, вокал) моделью в браузере (🔎 ONNX/WebGPU-реализации Demucs). Каждый элемент сцены реагирует на свой инструмент. Это заметно круче полос частот.
- Плавные переходы между стилями по таймлайну (сцены по меткам).
- 4K и 120 FPS для Pro.
- Полифил AAC: в браузерах без AAC-кодировщика mediabunny предлагает пакет `@mediabunny/aac-encoder`.
- Рендер в Web Worker через OffscreenCanvas: интерфейс не подтормаживает во время экспорта.
- WebGPU-рендер для тяжёлых сцен с частицами на GPU.

**Рост и маркетинг:**

- Водяной знак со ссылкой — бесплатная реклама в каждом ролике.
- Галерея «сделано в …» с примерами; шаблоны под жанры (phonk, lo-fi, techno).
- Интеграция с дистрибьюторами и ВК-клипами (🔎 проверить, есть ли API).
- Редактор стилей для продвинутых: свой GLSL с живым превью. Потом — маркетплейс стилей от сообщества с долей автору.

## 4. Технический долг прототипа

- Нет e2e-тестов UI (Playwright) и тестов экспорта в CI. Экспорт проверялся вручную в Chromium.
- Не проверены Firefox и Safari вживую.
- Очень длинные треки (30+ мин) держат весь MP4 в памяти (`BufferTarget`). Для них нужен `StreamTarget` и запись на диск через File System Access API (🔎 поддержка браузеров).
- Анализ хранит спектр `кадры × 64` в `Float32Array`. Для часового трека это ~55 МБ, терпимо, но можно хранить `Uint8Array`.
